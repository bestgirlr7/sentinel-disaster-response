# SENTINEL

Intelligent & Transparent Disaster Relief Resource Allocation — Team TECHTONIC.

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Main working interactions

- Landing screen + Launch Command Center + demo mode
- Dashboard with live KPIs, operations map, alerts, charts and explainable decision engine
- Disaster type, severity, impact radius, traffic and road-condition controls
- Patient triage with CRITICAL / SEVERE / MODERATE / STABLE reprioritization
- Capability-aware ambulance allocation (Basic / ALS / ICU / Neonatal)
- Hospital capacity, ICU, blood, ventilator and specialist matching
- Route ETA adjusted by disaster impact, traffic and road state
- Resource management for blood, ICU beds, medicines and emergency funds
- Separate Emergency Funds page with interactive allocation controls
- Allocation Decisions page with transparent reasoning
- Decision History + auditable-looking decision ledger
- Hackathon demo sequence that expands the disaster, blocks roads, reroutes, changes capacity and updates resources

## Notes

The simulation uses realistic synthetic data. The MapLibre map style is loaded from the public MapLibre demo tile service, so the map requires internet access at runtime. No blockchain security is claimed by the transparent ledger UI.
